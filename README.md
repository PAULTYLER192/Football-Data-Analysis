# Football-Data-Analysis
# International Football Results Analysis

## Project Setup

1. Create and activate a Python virtual environment.
2. Install dependencies with `pip install -r requirements.txt`.
3. Store source data in `data/raw/` and transformed outputs in `data/processed/`.
4. Use the notebooks in `notebooks/` for analysis and the scripts in `scripts/` for reusable logic.

## Visualizations

The `notebooks/Football_Insights.ipynb` notebook includes three core visualizations:

1. A histogram showing the distribution of goals per match.
2. A bar chart comparing home wins, away wins, and draws.
3. A horizontal bar chart ranking the top 10 winning teams historically.
